# Ledgerly web

The React interface for Ledgerly. It uses TypeScript, Vite, Tailwind CSS, and
shadcn/ui components. See the [root README](../README.md) for architecture,
Docker startup, demo data, and verification instructions.

```bash
npm install
npm run dev
```

The development server expects the Ledgerly API to be available through the
configured `/api` proxy.
