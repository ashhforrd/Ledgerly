# Demo checklist

1. Register and create a business workspace.
2. Create income and expense categories.
3. Record one income and one expense; verify the monthly report.
4. Preview a CSV containing valid, invalid, and duplicate rows, then confirm it.
5. Create a customer and invoice; send it and record a partial payment.
6. Show overdue filtering using a sent invoice with a past due date.
7. Create a description rule, add an uncategorized transaction, apply rules, and verify its category.
8. Void a transaction and show that the audit metadata remains available.

Never seed fabricated production-looking metrics for the demo. Create the records visibly so every displayed value has a traceable source.
